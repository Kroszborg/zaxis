## 📋 Component Template

Use this template when adding new components:

```typescript
// src/components/3d/[category]/[ComponentName].tsx
import { useRef, memo } from 'react';
import { useFrame } from '@react-three/fiber';
import * as THREE from 'three';
import { use3DAnimation } from '@/hooks/use3d-animation';
import { Component3DProps } from '@/types/component';

export const ComponentName = memo(function ComponentName({
  customization
}: Component3DProps) {
  const groupRef = useRef<THREE.Group>(null);

  // Use shared animation hook
  use3DAnimation(groupRef, customization);

  // Optional: Add custom animations
  useFrame((state) => {
    if (groupRef.current) {
      // Your animation logic
    }
  });

  return (
    <group ref={groupRef}>
      {/* Your 3D geometry */}
      <mesh>
        <boxGeometry args={[1, 1, 1]} />
        <meshStandardMaterial
          color={customization.color}
          metalness={customization.metalness}
          roughness={customization.roughness}
          emissiveIntensity={customization.emissiveIntensity}
        />
      </mesh>
    </group>
  );
});
```

## 🎨 Design Guidelines

### Complexity Levels

**Simple**:
- 1-3 mesh objects
- Basic geometries (box, sphere, cylinder)
- Single material
- Optional: basic rotation animation

**Medium**:
- 4-8 mesh objects
- Combined geometries
- 2-3 materials
- Custom animations or effects

**Complex**:
- 9+ mesh objects
- Advanced geometries or particle systems
- Multiple materials and effects
- Complex animations or interactions

### Performance Targets

- **Target FPS**: 60fps minimum
- **Polygon Budget**:
  - Simple: < 1,000 polygons
  - Medium: 1,000 - 5,000 polygons
  - Complex: 5,000 - 10,000 polygons
- **Memory**: Each component should use < 5MB memory

### Visual Quality Standards

1. **Realism**: Components should look recognizable
2. **Style**: Consistent with existing library aesthetic
3. **Colors**: Use theme-aware colors where appropriate
4. **Lighting**: Work well under default scene lighting
5. **Scale**: Proportionally correct relative to other objects
